# 🔌 ExpertBot Auto Login — Browser Extension

إضافة متصفح مستقلة تلتقط جلسة Expert Option تلقائياً وتفتح تطبيق ExpertBot Live.

## ✨ المميزات

- **تلقائي 100%**: لا نسخ أو لصق للتوكن
- **مستقلة**: لا تحتاج رفعها مع البوت على السيرفر
- **قابلة للتكوين**: غيّر رابط البوت من نافذة الإضافة (popup)
- **تعمل مع أي نسخة**: محلية أو منشورة على أي نطاق

## 📦 التثبيت

### Chrome / Edge
1. فك ضغط `expertbot-extension.zip` في مجلد
2. اذهب إلى `chrome://extensions`
3. فعّل **«وضع المطوّر»** (أعلى اليمين)
4. اضغط **«تحميل غير مُحزَّم»** ← اختر المجلد

### Firefox
1. اذهب إلى `about:debugging`
2. **«This Firefox»** ← **«Load Temporary Add-on»**
3. اختر ملف `manifest.json`

## ⚙️ الإعداد (مهم للنشر)

بعد تثبيت الإضافة:
1. اضغط على أيقونة الإضافة في شريط المتصفح
2. في حقل **«رابط التطبيق»**، أدخل نطاق البوت المنشور:
   - محلي: `http://localhost:81/`
   - منشور: `https://your-domain.com/`
3. يُحفظ تلقائياً

## 🔧 كيف تعمل

```
المستخدم يفتح app.expertoption.com
         ↓
content.js يشتغل على الصفحة
         ↓
يلتقط التوكن من localStorage / cookies / WebSocket
         ↓
يفتح رابط البوت + ?token=XXX في تبويب جديد
         ↓
البوت يلتقط التوكن من URL ويتصل بـ Expert Option
```

## 📁 الملفات

| الملف | الوظيفة |
|---|---|
| `manifest.json` | إعدادات الإضافة (MV3) |
| `content.js` | يلتقط التوكن من صفحة Expert Option |
| `background.js` | service worker يفتح تبويب البوت |
| `popup.html` | نافذة إعدادات الإضافة |
| `popup.js` | حفظ رابط البوت في chrome.storage |
| `icon.png` | أيقونة الإضافة |

## 🚫 لا حاجة لرفعها مع البوت

الإضافة تعيش في **متصفح المستخدم**، ليست جزءاً من السيرفر. يمكنك:
- توزيع `expertbot-extension.zip` من GitHub Releases
- أو من أي استضافة ملفات
- أو من البوت نفسه (اختياري)

المستخدم يثبّتها مرة واحدة، ثم يغيّر رابط البوت من popup حسب الحاجة.

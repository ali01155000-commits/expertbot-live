# 🖥️ ExpertBot Live — Desktop App (Electron)

تطبيق سطح مكتب يفتح منصة Expert Option في متصفح مدمج، ويتداول آلياً داخل الصفحة
بالضغط على أزرار Buy/Sell فعلياً.

## ✨ المميزات

- **متصفح مدمج**: Expert Option يفتح داخل التطبيق (يراه المستخدم كاملاً)
- **تداول داخل الصفحة**: البوت يضغط على أزرار Buy/Sell الفعلية في Expert Option
- **لا حاجة للتوكن**: المستخدم يسجل دخوله كالمعتاد، البوت يتحكم بالصفحة مباشرة
- **4 إستراتيجيات**: Trend · RSI · MA Cross · Alligator
- **تداول يدوي**: أزرار شراء/بيع سريعة
- **سجل نشاط** كامل + إحصائيات

## 🚀 التشغيل

### المتطلبات
- Node.js 20+ و npm
- Windows 10+ / macOS 11+ / Linux

### التثبيت والتشغيل (للمطورين)
```bash
cd desktop-app
npm install
npm start
```

### بناء ملف مثبّت للتوزيع
```bash
# Windows (ينتج ExpertBot-Live-Setup.exe)
npm run build:win

# macOS (ينتج ExpertBot-Live.dmg)
npm run build:mac

# Linux (ينتج ExpertBot-Live.AppImage)
npm run build:linux
```
ستجد الملفات في مجلد `dist/`.

## 📖 كيف يعمل

```
┌─────────────────────────────────────────────┐
│  ExpertBot Live (نافذة Electron)            │
│  ┌──────────────────────┬────────────────┐  │
│  │  <webview>           │  لوحة البوت    │  │
│  │  app.expertoption.com │  ─────────    │  │
│  │  ┌─────────────────┐ │  الإستراتيجية  │  │
│  │  │  صفحة Expert    │ │  الرهان        │  │
│  │  │  Option كاملة   │ │  المدة         │  │
│  │  │  (يسجل دخوله)   │ │  [تشغيل البوت] │  │
│  │  └─────────────────┘ │  [▲ شراء]      │  │
│  │                      │  [▼ بيع]       │  │
│  └──────────────────────┴────────────────┘  │
└─────────────────────────────────────────────┘
```

1. **Electron** يخلق نافذة مع `<webview>` يفتح Expert Option
2. **`main.cjs`** يلغي `X-Frame-Options` headers (السر الذي يجعل التضمين يعمل)
3. **المستخدم** يسجل دخوله في Expert Option كالمعتاد (يراه بالكامل)
4. **`inject.js`** يُحقن داخل الصفحة، يوفّر API للتحكم بالأزرار
5. **`renderer.js`** يشغّل البوت الذي يستدعي `inject.js` لضغط Buy/Sell

## 🔧 ملاحظات تقنية

- **لماذا هذا يعمل بينما الويب لا يعمل؟** Electron يتحكم بالـ HTTP stack ويمكنه
  إزالة `X-Frame-Options` headers. المتصفحات العادية لا تستطيع.
- **التحكم بالصفحة**: `webview.executeJavaScript()` ينفّذ كوداً داخل Expert Option
  بنفس امتيازات الصفحة — يمكنه ضغط الأزرار وقراءة البيانات.
- **الأمان**: كل شيء محلي — لا يُرسل شيء لأي خادم خارجي.
